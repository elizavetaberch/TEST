# Разбор реплеев SupCom 2

`tools/sc2rp.py` — парсер файлов `.SC2ReplayDLC`, написан с нуля по результатам разбора первого реплея.
Запуск: `python3 tools/sc2rp.py <реплей> [минуты_билда]`.

## Что уже читается
- **Заголовок:** версия игры (v1.26), карта, настройки лобби, игроки, фракции (1 = UEF, 2 = Cybran, 3 = Illuminate/Aeon), команды, seed.
- **Поток команд** (формат движка Moho, как у SupCom 1/FA, но с другими номерами операций):
  - op 0: шаг времени (10 тиков = 1 секунда);
  - op 1: какой игрок отдаёт следующую команду;
  - op 15 / 16: приказы юнитам и фабрикам: тип приказа, цель, **ID чертежа** (что строится);
  - op 18: **выбор исследования**: игрок + числовой ID технологии;
  - op 28: Lua-колбэки (выделение юнитов, пинги, самоуничтожение Ctrl + K и т. п.);
  - op 2 / 29: выход игрока / конец игры.

## Ограничения
- Реплей — это **только команды игроков**, без результатов: хода боя, HP, смертей юнитов и победителя в нём нет. Чтобы всё это получить, нужно прогнать симуляцию, то есть запустить реплей в самой игре.
- Приказ «построить» ≠ постройка (приказ могли отменить, а один мех заказать дважды).
- **Номера исследований (op 18) и коды юнитов нужно сопоставить с названиями.** Для этого нужны файлы игры (`gamedata/*.scd`) или список с вики. Расшифровка кодов ниже — догадка по частоте и контексту.

## Предварительная расшифровка кодов (u[фракция][тип][номер]; u = UEF, i = Illuminate, c = Cybran)
| Код | Вероятно |
|---|---|
| xxb0701 | экстрактор массы (мех) |
| xxb0702 | генератор энергии |
| xxb0801 | лаборатория (RS) |
| xxb0001 / xxb0002 | наземная / авиа фабрика |
| xxb0011 / xxb0012 | гантри (экспериментальная фабрика) |
| xxb01xx | турели (PD, ПВО и т. д.) |
| xxb02xx / xxb03xx | щиты, радар и пр. **(?)** |
| xxl0002 | инженер |
| xxl01xx / xxl02xx | наземные юниты |
| xxa01xx | авиация |
| xxm0xxx | улучшения фабрик или ACU **(?)** |
| xxx01xx | экспериментальки |
